# Bomb calorimetry

An interactive laboratory module on oxygen bomb calorimetry for an undergraduate physical chemistry course.

Open `index.html` in a web browser. It is a single self-contained page with no other files or installation needed.

## Contents

- **A. Principles:** internal energy at constant volume, the calorimeter energy balance, ΔU to ΔH, Hess's law, and temperature-rise correction. Includes a combustion-equation calculator and a thermogram simulator.
- **B. Experimental setup and procedure:** a labelled, clickable calorimeter diagram, an equipment list, safety notes and a step-by-step procedure.
- **C. Measurement worksheet:** enter data for two benzoic acid calibration runs and two sample runs. The page fits the drift lines and calculates C_cal, Δ_c u, Δ_c U, Δ_c H and Δ_f H°.
- **D. Pre-lab questions** with answer checking and worked solutions.
- **E. Post-lab questions** linked to the student's own worksheet results.
- **Review questions:** ten multiple-choice questions as a summary.
- **References.**

Worksheet entries and written answers are saved only in the browser that entered them. The example worksheet data and the explorer thermograms are simulated.
